# なんJ格闘技大会

拳と「レスバ返し」で完全論破する、スマホ＆PC対応の 2D 対戦格闘ブラウザゲームです。

## プレイする (GitHub Pages)

- **Game URL:** https://dma-cmyk.github.io/nanj-kakutougi/

## 特徴

- **肉弾戦 × レスバ返し**: パンチ・キック・足払い・飛び蹴りに加え、「効いてて草ァ！！」「お前が効いてる定期」などの吹き出し攻撃を搭載。
- **カウンターシステム**: 相手の煽り吹き出しに合わせて「レスバ」を押すと**「お前が効いてる定期」特大カウンター**が発動。
- **💢効いてる状態**: 煽り砲を食らうと顔真っ赤状態になり、攻撃力アップ＆被ダメージ増加のハイリスク状態に。
- **スマホ完全対応**: 縦持ち（上部ステージ＋下部専用アーケードパッド）・横持ち（全画面＋半透明コーナーパッド）の両対応。
- **4モード収録**: 3連戦トーナメント「大会モード」・CPUフリー対戦（3段階難易度）・PCローカル2P対戦・**サーバー不要P2Pオンライン対戦（ランダムマッチ / 合言葉ルーム / 招待URL）**。
- **敗北特典（看板公約）**: 負けると「時間の節約・メンタルケア・スラングの侵食防止」を獲得できます。

## 操作方法

### スマホ / タブレット
- **左スティック**: スライドで移動・しゃがみ・ジャンプ（左右2回素早く弾いてダッシュ）
- **弱 / 強**: パンチ・キック（前+強で突進、下+強で足払い）
- **煽 (レスバ)**: 吹き出し攻撃 / 相手の煽りに合わせてレスバ返し
- **防 (ガード)**: 攻撃を防御 / 直前ガードで「効いてないが？」ジャストガード
- **必 (必殺)**: POW 50%未満で気合チャージ、50%でEX技、100%で超必殺奥義

### PC キーボード（1P ソロ）
| 操作 | キー |
| --- | --- |
| 移動 / ジャンプ | `W A S D` または `↑ ← ↓ →`（左右2回押しでダッシュ） |
| 弱攻撃 | `J` / `Z` |
| 強攻撃 | `K` / `X`（前+強 / 下+強 で派生） |
| レスバ / カウンター | `L` / `C` |
| ガード | `Shift` / `U` / `V` |
| 必殺 / EX / 気合 | `Space` / `I` / `B` |

### PC 2P ローカル対戦
- **1P**: `W A S D` 移動 / `F` 弱 / `G` 強 / `H` レスバ / `R` ガード / `T` 必殺
- **2P**: `矢印キー` 移動 / `J` 弱 / `K` 強 / `L` レスバ / `U` ガード / `I` 必殺

### オンライン対戦 (P2P)
- **ランダムマッチ**: 待機中のプレイヤーと自動マッチングして対戦できます。
- **ルーム作成 / 合言葉参加**: ルームIDまたは招待URL（`?room=XXXXXX`）を共有するだけで友達とすぐ対戦できます。
- 1P・2P ともに通常のソロ操作（キーボード / スマホタッチパッド）でそのまま操作できます。
